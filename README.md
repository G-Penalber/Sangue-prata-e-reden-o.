# Sangue-prata-e-reden-o.
Jogo livro feito para a matéria de Introdução a programação da Universidade Federal de Ciência e Inovação do Rio de Janeiro (Ex-CEFET/RJ). Aluno Gabriel Oliveira Penalber e professora Ana Elisa Leitão.

Para rodar, é necessário ter como OS qualquer linux ou então utilizar o WSL com alguma build de linux. A utilizada no meu dispositivo (que possui um Windows 11) foi uma WSL de Ubuntu. A instalação da WSL deve ser feita pelo microsoft store e alguns tutoriais podem ser seguidos.

Para rodar o jogo, deve se estar dentro do diretorio ~/Sangue-prata-e-reden-o./JogoP2
E o comando [ gcc src/*.c -I include -o jogo_RPG -lncurses ] deve ser feito no terminal, a partir disso, pode se rodar o comando [ ./jogo_RPG ].
